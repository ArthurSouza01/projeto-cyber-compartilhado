  Esse é um projeto que está sendo desenvolvido durante o curso de graduação em defesa cibernética.

  A idéia é simples: centralizar funcionalidades de diversas ferramentas para que um usuário leigo tenha a capacidade de se proteger contra possíveis ameaças digitais.

  Inicialmente implementei análise de URL simples para verificar a quantidade de subdmínios e se há homógrafos, análise de domínio desde tempo de criação até análise mais aprofundada 
utilizando o VirusTotal. Essas análises criam pontuações que vão se somando e aumentando o nível de risco.
  
  Apesar do foco em URL e domínio neste início, a ideia é implementar mais funções, como por exemplo, análise de documentos e arquivos, análise de QR Code, análise de SSL/TLS...
